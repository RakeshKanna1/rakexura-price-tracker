### 🌟 Featured Project Showcase

#### 🎮 [Rakexura Price Tracker & Arbitrage Manager](https://github.com/RakeshKanna1/rakexura-price-tracker)
> A high-performance web dashboard designed to track PC game prices, identify profit arbitrage spreads across digital retailers, and manage resale business metrics.

- ⚡ **Snappy UI**: Zero-lag page changes built on in-memory Stale-While-Revalidate caching.
- 📱 **PWA Compatible**: Installable directly to mobile home screens for native experience.
- 🔗 **API Driven**: Leverages CheapShark's global price feeds combined with local Steam storefront currency indexes (INR, USD, etc.).
- 📊 **Business Intelligence**: Built-in ledgers for inventory purchases, customer order tracking, resale spreads, and net profit margins.
* **Tech Stack:** React, Vite, Tailwind CSS, Python, FastAPI, MongoDB, CheapShark API.

#### 🛍️ [Rakexura Game Store (Next.js Marketplace)](https://github.com/RakeshKanna1/rakexura-store)
> A premium, cinematic, production-ready Next.js e-commerce storefront for digital video games featuring robust customer and administrator dashboards.

- 🛒 **Rich Checkout Chain**: Features local/cloud persistent multi-game cart sync, server-verified coupon codes, and secure private payment-proof uploads.
- 🎨 **Cinematic UX**: Built with GSAP scroll animation effects, Lenis smooth scroll, Framer Motion transitions, and Swiper-based media galleries.
- 🛡️ **Secure Backend**: Relies on Supabase Auth (Email, Google, Discord OAuth), PostgreSQL database schemas, Row Level Security (RLS) policies, and database RPC validations.
- ⚙️ **Admin Suite**: Fully featured administration dashboard with metrics, review moderation queues, support tickets, and an uploaded media library with WebP compression.
* **Tech Stack:** Next.js 15, React 19, Tailwind CSS v4, Supabase (Auth, DB, Storage, RLS), Framer Motion, GSAP, Lenis, TypeScript.

#### 🤖 [Rockstar 2FA Verification Telegram Bot](https://github.com/RakeshKanna1/Rockstar-bot)
> A Python-powered automation tool designed to bypass login friction by extracting Rockstar Games 2FA verification codes directly from Gmail.

- 📧 **Gmail API Integration**: Monitors incoming emails in real-time to immediately retrieve OTP and security codes from `noreply@rockstargames.com`.
- 🔑 **License Manager**: Custom license creation and activation system using secure `RAKEXURA-XXXXXXXX` keys stored in MongoDB.
- 🔒 **Account Lock system**: Implements an active login lock mechanism to prevent account collisions during automated multi-client operations.
* **Tech Stack:** Python, Telegram Bot API, Google Gmail API, MongoDB (PyMongo), SQLite, Git.

#### 🔐 [GamerVault - Encrypted Credential Vault](https://github.com/RakeshKanna1/gamer-vault)
> A cyberpunk-themed, local-first credentials manager designed specifically for gamers to secure launcher accounts.

- 🔒 **Local AES Encryption**: Secure, password-derived AES cryptography to store sensitive credentials locally in the browser context.
- 👾 **Cyberpunk Aesthetics**: Interactive canvas node-network background and hacker-style text decryption scramble animations.
- 🎲 **Game Password Generator**: A unique password generator utility that derives highly secure, thematic passwords based on chosen game titles (e.g. Minecraft, Elden Ring, Skyrim, CS2, Cyberpunk).
* **Tech Stack:** React, TypeScript, Vite, Tailwind CSS, Crypto API, Lucide React.
